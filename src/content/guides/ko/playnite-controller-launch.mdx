Playnite 전체 화면 모드는 원래 컨트롤러 탐색을 지원합니다. Playnite의 전체 화면 바로 가기를 열거나 데스크톱 모드에서 F11로 전환한 뒤, 컨트롤러로 라이브러리를 탐색할 수 있는지 확인하세요. 이 기본 기능을 사용하기 위해 CouchMode를 설치할 필요는 없습니다.

게임패드를 연결할 때 Playnite도 함께 열고 싶다면 CouchMode를 선택적으로 사용할 수 있습니다. Windows가 호환되는 XInput 컨트롤러를 감지하면 Playnite 전체 화면 세션을 시작하는 실행 자동화 기능입니다. 이미 열린 라이브러리를 조작하거나 Xbox 버튼을 누르는 동작과는 구분해야 합니다.

## 먼저 Playnite 자체의 전체 화면 모드 확인하기

Playnite의 [전체 화면 모드 문서](https://api.playnite.link/docs/manual/gettingStarted/playniteFullscreenMode.html)에는 모드를 여는 방법과 입력 설정 확인 방법이 나와 있습니다. 자동 실행을 설정하기 전에 이 모드에서 라이브러리가 컨트롤러 입력에 반응하는지 확인하세요. 라이브러리 탐색은 Playnite의 기능이며, 게임 안에서의 조작은 해당 게임과 입력 설정이 담당합니다.

Playnite가 인식하는 컨트롤러라고 해서 반드시 CouchMode의 연결 트리거로도 사용할 수 있는 것은 아닙니다. 두 단계를 나눠 확인하세요. 먼저 Playnite를 수동으로 열어 조작한 다음, CouchMode에서 컨트롤러 연결을 시험해 보세요.

## Xbox 버튼으로 Playnite를 실행할 수 있나요?

닫혀 있는 Playnite가 Xbox 또는 Guide 버튼을 누르면 실행된다고 생각하지 마세요. Playnite에는 Guide 버튼으로 이미 실행 중인 전체 화면 창에 다시 포커스를 주는 옵션이 있습니다. 하지만 열린 창으로 입력 대상을 되돌리는 것과 닫힌 앱을 실행하는 것은 다릅니다. 다른 소프트웨어가 해당 버튼 입력을 받을 수도 있습니다.

CouchMode는 지원되는 컨트롤러의 연결과 사용자가 활성화한 세션 옵션에 따라 작동합니다. 물리적인 Xbox 버튼에 Playnite 실행을 할당하지 않습니다. 이미 연결된 컨트롤러에서 Guide 버튼을 다시 누르는 것은 새로운 연결 이벤트가 아닙니다.

## 컨트롤러 연결 시 Playnite 자동 실행하기

CouchMode에서 게임 환경으로 Playnite를 선택하고 컨트롤러 연결 트리거를 활성화하세요. Windows에 로그인한 상태에서 호환되는 컨트롤러 한 대를 연결합니다. CouchMode가 선택한 Playnite 전체 화면 세션을 시작할 수 있으며, 이 실행 기능은 Free에 포함됩니다.

Xbox 컨트롤러는 대표적인 XInput 장치입니다. 기본 방식으로 연결한 PS4 및 PS5 컨트롤러는 Playnite나 게임에서 작동하더라도 CouchMode 세션 트리거로는 지원되지 않습니다. Windows에 호환 XInput 장치로 표시되는 구성도 별도로 시험해야 합니다.

## 설치형 또는 포터블 Playnite 사용하기

CouchMode는 사용자 지정 위치에 설치한 Playnite와 포터블 설치 위치를 지원합니다. 사용하려는 Playnite가 정상적으로 열리고 라이브러리에 접근할 수 있는지, 실행 시험에서도 바로 그 Playnite가 열리는지 확인하세요. 포터블 폴더를 옮겼다면 TV에서 사용하기 전에 다시 시험하는 것이 좋습니다.

CouchMode는 Playnite의 라이브러리, 확장 기능이나 컨트롤러 매핑을 관리하지 않습니다. 확장 기능에 문제가 있거나 첫 실행 대화상자가 나타나면 Playnite에서 직접 처리해야 합니다.

## Playnite가 이미 열려 있다면

CouchMode는 인스턴스를 하나 더 시작하는 대신 기존 Playnite 상태를 활용합니다. 프로세스가 실행 중이어도 창은 최소화되어 있거나 뒤에 숨어 있을 수 있습니다. 눈에 보이는 전체 화면 인터페이스가 실제로 컨트롤러 입력을 받는지 확인하세요.

마우스로 클릭하자 갑자기 컨트롤러가 작동한다면 [Playnite 포커스 확인 가이드](content:guide-playnite-focus)를 참고하세요. 실행 설정을 계속 바꾸기보다는 드라이버나 버튼 매핑 문제를 창 포커스 문제와 구분해 살펴보세요.

## 세션 전체 흐름을 한 번 시험하기

컨트롤러 한 대와 실제 사용할 디스플레이를 준비하고 Windows에 정상적으로 로그인하세요. Playnite가 열리고 입력에 반응하는지 확인한 뒤, 세션을 종료하고 바탕 화면도 확인합니다. CouchMode는 직접 변경한 지원 설정을 복원합니다. Windows를 대체하거나 창의 위치와 크기를 정확히 재현한다고 보장하지는 않습니다.

기본 흐름이 잘 작동하면 [Windows PC를 콘솔처럼 사용하는 가이드](content:guide-windows-console)를 참고해 선택적인 디스플레이나 오디오 자동화가 반복 작업을 줄여 줄지 판단해 보세요.
