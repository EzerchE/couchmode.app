Xbox 모드는 지원되는 Windows 11 PC에서 컨트롤러로 탐색할 수 있는 게임 인터페이스를 제공합니다. 전체 화면 환경(Full Screen Experience, FSE)이라는 이름으로 표시되기도 합니다. Windows 설정에서 내 PC에 이 모드가 제공되는지 확인한 다음, 자동화를 추가하기 전에 직접 들어가고 나오는 과정을 시험하세요.

Xbox 모드는 CouchMode 없이도 사용할 수 있습니다. 이 가이드에서는 먼저 Windows의 설정 방법을 살펴보고, 이후 선택적으로 사용하는 컨트롤러 연결 기반 CouchMode 세션이 어디에 해당하는지 설명합니다.

## Windows 11의 Xbox 모드란?

Xbox 모드는 게임 홈 앱과 컨트롤러 중심 탐색 기능을 갖춘 Windows 게임 환경입니다. 모드 안에서 런처, 게임과 다른 앱 사이를 이동하는 방식이 달라집니다. 바탕 화면으로 돌아오면 Windows를 계속 사용할 수 있습니다.

[Windows PC를 콘솔처럼 쓰기](content:guide-windows-console) 위한 선택지 중 하나입니다. 어떤 게임을 플레이하고 어떤 인터페이스를 화면에 띄우고 싶은지에 따라 적합한 선택이 달라집니다.

## 내 PC에서 Xbox 모드를 사용할 수 있나요?

Microsoft는 Windows 11 24H2 이상과 지원 지역에서의 제공을 명시합니다. 버전 번호가 조건에 맞는다는 것만으로 내 기기에 해당 옵션이 활성화되어 있다고 판단할 수는 없습니다. 지원되는 휴대용 게이밍 PC와 다른 PC 유형은 설정이나 진입 방법이 서로 다를 수 있습니다.

Windows 업데이트를 확인하고 설정 > 게임 > Xbox 모드에 실제로 어떤 옵션이 표시되는지 살펴보세요. 설정이 없다면 [Microsoft의 최신 제공 조건 및 설정 안내](https://support.microsoft.com/en-us/servicing/os/windows/docs/2025/10/windows-gaming-full-screen-experience)를 확인하세요. CouchMode는 제공되지 않는 Windows 기능을 나타나게 할 수 없습니다.

## Xbox 모드 활성화하고 진입하기

지원되는 데스크톱 또는 노트북에서는 설정 > 게임 > Xbox 모드를 열어 활성화하세요. 지원되는 휴대용 게이밍 PC에서는 같은 설정 페이지에서 설치된 게임 홈 앱을 선택합니다. 정확한 선택 항목은 기기에 따라 달라집니다.

Xbox 앱, Game Bar, 작업 보기에 제공되는 진입 기능을 사용하거나, 설정된 환경에서는 Win+F11을 시도하세요. 실제 Xbox 모드에 들어갔고 컨트롤러로 탐색할 수 있는지 확인한 다음 바탕 화면으로 돌아오는 방법도 익혀 두세요. 설정 또는 로그인 메시지가 나타나면 컨트롤러만으로 시작하려 하기 전에 직접 완료해야 합니다.

## 데스크톱·노트북·휴대용 게이밍 PC에서의 차이

휴대용 게이밍 PC는 시작 옵션을 통해 로그인 후 Xbox 모드로 진입하는 기능을 제공할 수 있습니다. 이는 데스크톱에 외부 컨트롤러를 연결하는 것과 다릅니다. 휴대용 PC의 내장 컨트롤러는 부팅 내내 이미 존재할 수 있으므로, 내장 조작부가 있다는 사실을 새로운 외부 연결로 취급하면 안 됩니다.

자체 화면과 독을 모두 사용한다면 두 환경에서 각각 시험하세요. TV, 리시버 또는 독은 Windows가 인식하는 디스플레이와 오디오 장치를 바꿀 수 있습니다. 이 부분은 [휴대용 게이밍 PC의 TV 연결 가이드](content:guide-windows-handheld)에서 다룹니다.

## Xbox 모드와 Xbox 앱 열기·최대화는 다릅니다

Xbox 앱 창이 크게 보인다는 것만으로 Windows가 Xbox 모드에 진입했다고 판단할 수 없습니다. 지원되는 모드 진입 기능으로 시작한 뒤 탐색 방식과 바탕 화면으로 돌아가기 기능을 확인하세요.

자동화를 시험할 때도 이 구분은 중요합니다. 런처가 나타났다면 앱이 열렸다는 것은 확인할 수 있지만, 그것만으로 의도한 Windows 게임 환경이 활성화되었다고 볼 수는 없습니다.

## 컨트롤러로 게임 세션 자동 시작하기

수동 진입이 잘 작동하면 선택적으로 CouchMode에서 지원되는 Xbox 환경을 고르고 세션 트리거를 설정할 수 있습니다. Windows가 지원하는 환경에서 Xbox 모드 실행은 CouchMode Free에 포함됩니다. 외부 컨트롤러 트리거는 Windows가 호환 XInput 연결을 감지해야 작동합니다. 컨트롤러의 전원 또는 Guide 버튼을 매핑하는 기능이 아닙니다. 기본 방식의 PS4 또는 PS5 연결을 범용 CouchMode 트리거로 사용할 수 있는 것은 아닙니다.

내장 조작부가 있는 휴대용 게이밍 PC에서는 기기에 맞는 시작·세션 옵션을 사용하고 외부 게임패드와 별도로 시험하세요. 선택적인 Pro [HDR·디스플레이·오디오 설정](content:guide-controller-session-settings)은 사용자가 고른 지원 항목에만 적용됩니다.

## 컨트롤러 연결이 끊어지면 어떻게 되나요?

Exit CouchMode when controller disconnects(컨트롤러 연결 해제 시 CouchMode 종료)를 켜 둔 경우 배터리 부족이나 무선 연결 끊김으로도 세션 종료가 시작될 수 있습니다. CouchMode는 설정된 연결 해제 지연 시간(offDelay) 동안 기다리며, 그 안에 다시 연결하면 대기 중인 종료가 취소될 수 있습니다. 전체 화면 앱이 열려 있다는 이유만으로 연결 해제를 무시하지 않습니다.

CouchMode는 종료 전에 기록된 세션 관리 범위와 실제 전체 화면 상태를 확인합니다. 세션 기록상 FSE 종료를 담당하고 있으며 FSE가 여전히 활성 상태인 경우에만 해당 FSE 종료 동작을 보냅니다. FSE가 이미 비활성 상태라면 다시 전환하지 않습니다. 사용자가 직접 열었거나 기존에 열려 있던 런처와 앱은 강제로 닫지 않으며, 안전하게 바탕 화면으로 돌아왔는지 확인합니다. 설정한 종료 동작은 안전한 상황에서 시험하고, 우발적으로 연결이 끊어졌다면 다시 연결하세요. 의도적으로 세션을 끝내기 전에는 게임을 저장하세요.

## Windows 바탕 화면으로 안전하게 돌아가기

Game Bar 또는 작업 보기에서 제공하는 바탕 화면 복귀 기능을 사용하거나, 지원되는 환경에서는 Win+F11을 누르세요. CouchMode 세션의 목표는 Windows를 계속 사용할 수 있게 하고 CouchMode가 직접 변경한 지원 설정을 복원하는 것입니다. 기존 앱은 불필요하게 닫거나 위치를 바꾸지 않고 계속 사용할 수 있어야 하지만, 창의 정확한 위치와 크기까지 보장하지는 않습니다.

Pro의 Resource Control도 켜 두었다면 선택한 앱 중 접근 가능한 앱만 대상이 됩니다. 관리자 권한으로 실행된 프로세스, 서비스 형태의 프로세스, 스스로 재실행되는 프로세스는 계속 실행될 수 있습니다. 이러한 별도 선택 사항은 [선택한 앱 관리와 바탕 화면 복원 가이드](content:guide-resource-control-session-restore)에서 설명합니다.

## Steam Big Picture 모드나 Playnite가 더 잘 맞는 경우

세션 주변 작업을 최적화하기 전에 라이브러리와 컨트롤러에 맞는 런처부터 고르세요. Steam을 중심으로 쓴다면 [Steam Big Picture 모드](content:guide-steam-big-picture)가 대안이고, 여러 라이브러리를 모으고 싶다면 [Playnite 전체 화면 모드](content:guide-playnite-launch)를 고려할 수 있습니다. 둘은 비교해 볼 대안이지 Xbox 모드의 필수 조건이 아닙니다.

평소 사용하는 소프트웨어를 열어 둔 상태에서 수동 시작과 바탕 화면으로 돌아가기를 각각 한 번 시험해 보세요. 그 결과를 기준으로 반복 작업 중 CouchMode에 맡기고 싶은 것이 있는지 판단할 수 있습니다.
