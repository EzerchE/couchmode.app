Steam이 이미 실행 중이라면 Steam 클라이언트를 사용하는 동안 컨트롤러의 Home 또는 Guide 버튼으로 Big Picture 모드(빅 픽처)를 열 수 있습니다. 해당 컨트롤러와 설정이 이 동작을 지원해야 합니다. 이 기본 기능에는 CouchMode가 필요하지 않습니다. Steam을 시작하고 컨트롤러가 인식되는지 확인한 다음 버튼을 눌러 보세요.

버튼으로 Big Picture 모드를 여는 것과 컨트롤러 연결 시 게임 세션을 시작하는 것은 서로 다른 동작입니다. Steam의 인터페이스는 Steam이 관리합니다. CouchMode는 호환 컨트롤러가 연결될 때 선택한 게임 환경을 실행하고, 사용자가 고른 지원 세션 설정을 관리하는 선택적인 방법입니다.

## Xbox 컨트롤러로 Steam Big Picture 모드 열기

Xbox 컨트롤러를 Windows에 연결하고 Steam을 여세요. Steam 클라이언트를 사용하는 상태에서 Xbox 버튼을 눌러 Big Picture 모드가 열리는지 확인합니다. Valve의 [Big Picture 가이드](https://help.steampowered.com/en/faqs/view/3725-76D3-3F31-FB63)는 컨트롤러의 Home 버튼을 기본 진입 방법으로 안내합니다.

대신 Game Bar나 다른 오버레이가 열린다면 Steam 설정의 컨트롤러 및 Guide 버튼 옵션과 어떤 앱이 버튼 입력을 받는지 확인하세요. 구성을 바꾸기 전에 Steam의 Big Picture 모드 진입 버튼으로 인터페이스 자체를 시험해 보세요. Xbox 버튼은 닫혀 있는 Steam 클라이언트를 실행하는 범용 Windows 명령이 아닙니다.

## 지원되는 PlayStation 컨트롤러 구성 사용하기

Steam Big Picture 모드는 정품 DualShock 4와 DualSense 컨트롤러를 지원합니다. 컨트롤러를 연결한 뒤 먼저 Steam의 컨트롤러 설정을 확인하세요. 현재 구성에서 Home 또는 PS 버튼으로 Big Picture 모드에 진입하는지 시험해 보세요. Steam Input, Windows, 다른 컨트롤러 도구에 따라 버튼 입력을 받는 대상이 달라질 수 있습니다.

Steam의 컨트롤러 지원과 CouchMode의 자동 시작 트리거는 별개입니다. 기본 방식의 PS4 또는 PS5 연결은 CouchMode 세션 트리거로 지원되지 않습니다. Windows가 호환 XInput 장치로 인식하는 구성이라면 작동할 수 있지만, Steam 게임에서 컨트롤러가 된다는 이유만으로 자동 연결 트리거도 된다고 단정하지 마세요.

## 컨트롤러 연결 시 Big Picture 모드 자동 시작하기

자동 시작을 원하면 CouchMode에서 게임 환경으로 Steam Big Picture 모드를 선택하고 컨트롤러 연결 트리거를 활성화하세요. Windows가 호환 XInput 컨트롤러를 감지하면 CouchMode가 해당 세션을 시작할 수 있습니다. Xbox 컨트롤러를 켜면 대개 연결이 이루어지지만, CouchMode가 물리적인 전원 또는 Guide 버튼을 매핑하는 것은 아닙니다.

이 실행 기능은 CouchMode Free에 포함됩니다. 먼저 컨트롤러 한 대와 평소 사용하는 디스플레이로 시험하세요. 지원되는 [HDR·디스플레이·오디오 설정](content:guide-controller-session-settings) 같은 선택적인 Pro 기능은 기본 시작이 잘 작동한 다음 추가하면 됩니다.

## Steam이 실행 중이 아니라면

선택한 Big Picture 세션을 시작하는 데 필요하면 CouchMode가 Steam을 실행할 수 있습니다. Steam이 설치되어 있고 정상적으로 시작할 수 있어야 합니다. 컨트롤러만으로 시작하기에 앞서 로그인, 업데이트, 첫 실행 안내를 직접 완료하세요.

세션 자동화를 쓰지 않는 경우에는 먼저 Steam을 열고 Steam 자체의 Big Picture 진입 기능을 사용하면 됩니다. 어느 방법도 계정 또는 보안 메시지에 대신 안전하게 응답해 주지는 못합니다.

## 이미 실행 중인 Steam 세션은 어떻게 되나요?

Steam은 알림 영역에서 실행 중인 경우가 많지만, 그것이 Big Picture 모드가 열려 있다는 뜻은 아닙니다. CouchMode는 Steam 프로세스를 중복 실행하지 않으며, 자신의 세션을 시작하기 전부터 열려 있던 Big Picture 세션은 유지합니다.

이미 진행 중인 게임, 다운로드 또는 Remote Play 연결이 있다면 기존 상태를 유지하는 것이 중요합니다. 컨트롤러 연결이 끊어질 때 세션 유틸리티가 모든 Steam 창을 닫아도 된다고 생각해서는 안 됩니다.

## 게임 세션을 마치고 바탕 화면으로 돌아가기

Steam 메뉴에서 Big Picture 모드를 종료할 수 있습니다. CouchMode가 시작한 세션을 끝내면 CouchMode는 직접 변경한 지원 설정을 복원합니다. 다시 사용할 수 있는 바탕 화면으로 돌아가는 것이지, 모든 창의 정확한 위치를 재현한다는 약속은 아닙니다.

전체적인 구성은 [Windows PC를 콘솔처럼 사용하는 가이드](content:guide-windows-console)를 참고하세요. 독에 연결한 휴대용 게이밍 PC라면 연결 이벤트로 세션을 시작하기 전에 [휴대용 PC와 TV 설정](content:guide-windows-handheld)부터 확인하세요.
