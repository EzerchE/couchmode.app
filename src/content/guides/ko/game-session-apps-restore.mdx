컨트롤러로 게임을 시작할 때 평소 열어 두는 데스크톱 앱이 방해가 될 수 있습니다. CouchMode Pro의 Resource Control에서는 지원되는 앱 중 게임 세션 동안 닫을 앱을 직접 선택합니다. 모든 Windows 프로세스를 강제로 종료하는 명령이 아닙니다.

세션이 끝난 뒤 선택한 앱이 다시 열리도록 설정할 수도 있습니다. CouchMode는 해당 세션에서 직접 변경한 지원되는 Windows 설정도 복원합니다. 덕분에 바탕 화면이 게임용 설정에 머무르지 않고 미리 준비한 환경으로 돌아갈 수 있습니다.

## 관리할 앱을 직접 선택하기

앱은 신중히 선택하세요. 게임 중 화면 공간을 차지하거나 주의를 분산시키는 브라우저, 채팅 앱 또는 다른 데스크톱 앱을 고를 수 있습니다. CouchMode는 지원되는 앱 중 사용자가 선택한 앱만 대상으로 삼습니다. 선택하지 않은 앱은 의도적으로 닫지 않습니다.

처음에는 짧은 목록으로 시작하세요. 종료와 재실행이 자신의 사용 방식에 맞게 작동하는지 확인한 다음 앱을 추가하는 편이 좋습니다.

## Resource Control이 닫지 않는 항목 알아두기

일부 프로세스는 이 자동화의 대상 밖에 있어야 합니다. 서비스, 보호된 Windows 구성 요소, 관리자 권한으로 실행한 앱, 접근할 수 없는 프로세스, 스스로 다시 실행되는 앱은 계속 실행될 수 있습니다. CouchMode는 이런 경우를 강제 종료로 안전하게 해결할 수 있는 오류로 보지 않습니다.

진행 중인 작업에 중요한 앱은 안전한 예제로 세션을 시험할 때까지 목록에서 제외하세요. Resource Control은 사용자가 선택한 방해 요소를 줄이기 위한 기능이지, 임의의 Windows 프로세스에 대해 대신 판단하는 기능이 아닙니다.

## 게임 세션 종료 후 동작 설정하기

재실행 옵션을 설정했고 지원되는 경우에만 선택한 앱을 세션 종료 후 다시 열 수 있습니다. 이는 선택 사항입니다. CouchMode가 직접 시작한 세션을 종료하며 지원되는 Windows 설정을 복원하는 기능과는 별개입니다.

Exit CouchMode when controller disconnects(컨트롤러 연결 해제 시 CouchMode 종료)를 켜 두었다면 지원 컨트롤러의 연결이 끊어진 후 설정된 지연 시간(offDelay)이 지나 세션 종료가 시작됩니다. 그 사이에 다시 연결하면 대기 중인 종료가 취소될 수 있습니다. CouchMode는 기록된 세션 관리 범위에 따라 자신이 종료할 책임이 있는 게임 환경을 닫고, 직접 변경한 지원 설정을 복원하고, 설정된 세션 종료 후 작업을 적용한 다음 안전하게 바탕 화면으로 돌아왔는지 확인합니다. 세션 시작 전부터 열려 있던 런처나 앱은 강제로 닫지 않습니다.

## 자주 묻는 질문

### 게임을 시작할 때 Discord나 Chrome을 닫을 수 있나요?

지원되는 Discord 또는 Chrome 프로세스를 Resource Control에서 직접 선택한 경우에만 닫을 수 있습니다. 모든 백그라운드 앱을 자동으로 닫지는 않습니다.

### 선택한 앱이 그대로 열려 있는 이유는 무엇인가요?

관리자 권한, 보호 상태, 서비스와 같은 실행 방식, 접근 제한 또는 자동 재실행 설정 때문일 수 있습니다. 이런 경우에는 강제 종료하지 않고 계속 실행될 수 있습니다.

### 게임이 끝나면 앱이 다시 열리나요?

재실행 동작을 설정했고 CouchMode가 이를 지원하는 경우에만 가능합니다. 이와 별개로 바탕 화면 복원의 대상은 CouchMode가 자신의 세션 중 직접 변경한 지원되는 Windows 설정입니다.

같은 게임 세션의 디스플레이, HDR, 오디오 옵션은 [컨트롤러 세션 설정 가이드](content:guide-controller-session-settings)를 참고하세요.
