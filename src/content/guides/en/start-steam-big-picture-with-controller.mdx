To start Steam Big Picture automatically when a controller connects, select Steam Big Picture as the CouchMode gaming experience. When Windows detects a compatible controller, CouchMode can start the session you selected. Steam Big Picture is available in CouchMode Free, so this controller-to-Big-Picture path does not require Pro.

That arrangement is useful for a PC connected to a television because Steam can remain installed, updated, and signed in as usual. The controller becomes the deliberate start signal, instead of asking you to navigate the Windows desktop each time you want to play.

## Steam may already be running

Steam is often running in the notification area long before a couch session begins. That is normal. A controller-first flow should not assume that a running Steam process means Big Picture is already the active experience, and it should not launch duplicate Steam processes just to get there.

First make sure Steam can open Big Picture normally on its own. Sign in, complete any pending update, and check that the TV is the display you expect to use. Those checks rule out account prompts and first-run dialogs that no session launcher can safely answer for you.

## Start Big Picture, then keep session ownership clear

CouchMode can launch Steam Big Picture as part of a session it begins. If Big Picture is already open from before CouchMode starts, CouchMode preserves that pre-existing session instead of claiming ownership of it. This prevents a session utility from closing or changing an experience it did not create.

That behavior can look conservative, but it is intentional. A pre-existing Big Picture session may contain an active game, a download, a remote-play connection, or a person using Steam at the desk. Preserving it is safer than trying to infer that every open Steam window should be reset when a controller disconnects.

## Use a compatible controller for the trigger

Use a controller that Windows exposes through the supported compatibility path, such as an Xbox controller. Some controllers can be configured to appear as Xbox-compatible XInput devices on Windows, but that configuration is outside CouchMode. Verify that Windows and Steam both see the controller before expecting it to start a session.

Every controller connection does not work natively as a session trigger. In particular, native PlayStation controller connections have a current trigger limitation. A PS4 or PS5 controller can still work in Steam games, but if it needs an adapter or another Windows compatibility layer to appear as XInput, test the complete path before making it your usual way to start a session.

## Return to a usable desktop

When the session CouchMode started is finished, it returns the supported settings it changed. Your normal Windows desktop remains your desktop; CouchMode is not a replacement shell and does not turn Steam into the operating system. This makes the same machine practical for a desk during the day and a controller-led TV setup later.

Pro can automate additional supported preferences such as audio, display, power, notification, Resource Control, and app-cleanup choices. Those options are separate from the Free Big Picture launch flow, so start with the simple route and add automation only where it solves a repeatable step.

## Common questions

### Can an Xbox controller open Steam Big Picture when I turn it on?

It can when turning it on results in Windows connecting a compatible XInput controller and Steam Big Picture is the selected CouchMode gaming experience. The technical trigger is the compatible Windows connection, not the physical power button on every controller.

### What if Steam is already running?

Steam running in the notification area is normal. CouchMode avoids starting a duplicate Steam process. If Big Picture was already open before the CouchMode session, CouchMode preserves that pre-existing session instead of treating it as one it owns.

### Can a PlayStation controller start Steam Big Picture automatically?

Not through its native connection mode. Where Windows exposes a configured setup as XInput, CouchMode can treat it like another compatible XInput controller. Test that configuration before depending on it.
