If Steam is already running, you can open Big Picture with the controller's Home or Guide button while using the Steam client, where that controller and configuration support it. You do not need CouchMode for this basic action. Start Steam, check that it sees your controller, then try the button.

Opening Big Picture with a button and starting a gaming session when a controller connects are different actions. Steam handles its own interface. CouchMode is an optional way to launch the selected experience on a compatible controller connection and manage the supported settings you choose for that session.

## Open Steam Big Picture with an Xbox controller

Connect the Xbox controller to Windows and open Steam. With the Steam client in use, press the Xbox button and check whether Big Picture opens. Valve documents the controller Home button as a native entry point in its [Big Picture guide](https://help.steampowered.com/en/faqs/view/3725-76D3-3F31-FB63).

If the button opens Game Bar or another overlay instead, check the controller and Guide-button options in Steam Settings and which app is receiving the button. Use Steam's Enter Big Picture Mode button to test the interface itself before changing your setup. Pressing the Xbox button is not a general Windows command to launch a closed Steam client.

## Use a supported PlayStation controller setup

Steam Big Picture supports official DualShock 4 and DualSense controllers. Connect the controller and check Steam's controller settings first. Test whether the Home or PS button enters Big Picture in your configuration; Steam Input, Windows and other controller tools can affect where that button goes.

Steam's controller support is separate from CouchMode's automatic-start trigger. A native PS4 or PS5 connection is not a supported CouchMode session trigger. A setup that Windows exposes as a compatible XInput device may work, but do not assume that a controller working in a Steam game proves that the automatic trigger will work too.

## Start Big Picture automatically when the controller connects

For automatic startup, choose Steam Big Picture as the gaming experience in CouchMode and enable the controller-connection trigger. When Windows detects a compatible XInput controller, CouchMode can begin that session. Turning on an Xbox controller often creates that connection; CouchMode is not mapping the physical power or Guide button.

This launch path is included in CouchMode Free. First test one controller and the display you normally use. Optional Pro preferences, such as supported [HDR, display and audio settings](content:guide-controller-session-settings), can be added after the basic start works.

## What if Steam is not already running?

CouchMode can launch Steam for the selected Big Picture session when needed. Steam must be installed and able to start normally. Sign in and complete updates or first-run prompts manually before relying on a controller-only start.

Without session automation, open Steam first and then use its native Big Picture entry point. Neither method can safely answer account or security prompts for you.

## What happens to an already-running Steam session?

Steam often runs in the notification area. That does not mean Big Picture is open. CouchMode avoids launching duplicate Steam processes, and preserves a Big Picture session that was already open before CouchMode began its own session.

An existing game, download or Remote Play connection is a reason to preserve the current state. Do not treat every Steam window as something a session utility should close when a controller disconnects.

## Return to the desktop when the gaming session ends

Steam lets you leave Big Picture through its menu. When you end a session started by CouchMode, it restores the supported settings it changed. This is a return to a usable desktop, not a promise to reproduce every window's exact position.

For the wider setup, use the [Windows console-style PC guide](content:guide-windows-console). If the computer is a docked handheld, check the [handheld and TV setup](content:guide-windows-handheld) before relying on a connection event to begin the session.
