To launch Playnite automatically when a controller connects, choose Playnite as the CouchMode gaming experience. When Windows detects a compatible controller, CouchMode can start the Playnite Fullscreen session you selected, so you do not have to reach for a mouse before playing.

This works well when a gaming PC is connected to a TV. The computer stays a normal Windows PC for everything else, while a controller connection becomes the signal to start the gaming session.

## Use Playnite Fullscreen as the destination

Playnite Fullscreen is designed for controller navigation, so it is a natural destination for a couch setup. In CouchMode, choose Playnite as the launch mode and make sure Playnite itself is installed and able to open normally on the PC first. The Free edition includes Playnite as a gaming experience; you do not need Pro just to launch it from a controller-led session.

Before relying on any automation, open Playnite once and confirm that Fullscreen mode is the experience you expect on the TV. That gives you a simple baseline: if Playnite cannot start cleanly by itself, a session utility cannot make its library, extensions, or display configuration behave differently.

## What happens when Playnite is already open

Many people leave Playnite running between sessions. CouchMode avoids treating that as permission to create a second instance. When the existing Playnite window is available, the goal is to bring the user-facing Playnite experience forward rather than duplicate a process that may already own the library or Fullscreen session.

The distinction matters because a running process is not always a usable window. Playnite can be minimized, behind another application, or visible without being the focused window that receives controller input. If it looks open but the controller appears unresponsive, read the related guide on Playnite Fullscreen focus before changing launch settings repeatedly.

## Start with a compatible controller

CouchMode reacts when Windows exposes a compatible controller through the supported path. An Xbox controller is the straightforward example. A controller that Windows or another tool presents as an Xbox-compatible XInput device can also be suitable, depending on its configuration.

Native PlayStation controller connections have an important limitation: they are not native CouchMode session triggers. That does not mean a PS4 or PS5 controller cannot be used in games. It means you should not expect every controller connection to begin a CouchMode session unless Windows presents that setup as XInput. Check the current compatibility guidance before relying on a particular controller.

## Keep the first session simple

For the first test, turn on the TV, sign in to Windows, and connect one compatible controller. Confirm that Playnite opens in the expected mode and that controller input reaches the focused Playnite window. Once this works, add optional session choices such as supported display or audio preferences available in your CouchMode plan.

If a manual mouse click makes Playnite start responding, that is a useful clue rather than a reason to keep clicking it. It usually points to window focus, a minimized state, or another application sitting in front of Playnite. Start by closing or minimizing the competing app, then test again with the same controller and TV input.

## Where CouchMode helps

CouchMode uses the compatible controller connection as the start of the gaming flow and returns the supported settings it changed when the session ends. It does not replace the Windows shell or promise that every desktop window will behave like a console interface. Playnite remains the library and launcher; CouchMode is the session layer around it.

## Common questions

### Can an Xbox controller start Playnite automatically?

Yes. An Xbox controller is the clearest supported example because Windows exposes it through XInput. Choose Playnite as the launch target first, then test the complete controller-to-Playnite path with the TV and display you actually use.

### Why does Playnite open but not respond to the controller?

That is often a Fullscreen focus problem rather than a failed launch. Check the related Playnite focus guide before changing the automatic-start setup.

### Can a PS5 or PS4 controller trigger Playnite automatically?

Not in its native connection mode. A PlayStation controller can be used in games, but CouchMode starts sessions only when Windows presents the controller through the supported XInput path.

When the setup is ready, download CouchMode from the official download page and test it with the controller and display you actually use. If you find a controller, dock, or Playnite edge case worth documenting, share the details with the CouchMode community.
