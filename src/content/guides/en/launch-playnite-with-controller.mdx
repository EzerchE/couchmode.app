Playnite Fullscreen already supports controller navigation. Open Playnite's Fullscreen shortcut, or switch from Desktop mode with F11, and check that you can browse the library with your controller. CouchMode is not needed to add this native support.

If you want Playnite to open when you connect a gamepad, CouchMode can start a Playnite Fullscreen session when Windows detects a compatible XInput controller. That is optional launch automation. It is separate from navigating an open library or pressing the Xbox button.

## Start with Playnite's own Fullscreen mode

Playnite's [Fullscreen documentation](https://api.playnite.link/docs/manual/gettingStarted/playniteFullscreenMode.html) explains how to open the mode and check its input settings. Confirm the library responds there before setting up an automatic start. Controller navigation belongs to Playnite; game-specific controls belong to the game and its input setup.

A controller recognized by Playnite is not automatically a compatible CouchMode trigger. Test both parts separately: first navigate Playnite manually, then test a controller connection with CouchMode.

## Does the Xbox button launch Playnite?

Do not assume the Xbox or Guide button starts Playnite when it is closed. Playnite has an option to use the Guide button to refocus its running Fullscreen window, but refocusing a window is not launching a closed application. Other software may receive that button instead.

CouchMode reacts to a supported controller connection and the session options you enable. It does not assign the physical Xbox button to Playnite. If the controller was already connected, pressing Guide again is not a new connection event.

## Open Playnite automatically when a controller connects

Choose Playnite as the gaming experience in CouchMode and enable the controller-connection trigger. Connect one compatible controller while signed in to Windows. CouchMode can start the selected Playnite Fullscreen session; this launch path is included in Free.

Xbox controllers are the straightforward XInput example. Native PS4 and PS5 connections are not supported CouchMode session triggers, even when Playnite or a game accepts them. A setup exposed to Windows as compatible XInput needs its own test.

## Use an installed or portable copy of Playnite

CouchMode supports custom and portable Playnite installation locations. Check that the copy you intend to use opens normally, that its library is available, and that your launch test reaches that copy. Moving a portable folder should be followed by another test before relying on it from the TV.

CouchMode does not manage Playnite's library, extensions or controller mappings. A broken extension or first-run dialog still needs attention in Playnite itself.

## What if Playnite is already open?

CouchMode works with the existing Playnite state instead of starting another instance. A running process may still have a minimized or background window. Check that the visible Fullscreen interface is receiving controller input.

If a mouse click suddenly makes the controller work, follow the [Playnite focus checks](content:guide-playnite-focus). Keep driver and button-mapping questions separate from window focus rather than repeatedly changing launch settings.

## Test the whole session once

Use one controller, the intended display and a normal Windows sign-in. Confirm that Playnite opens and responds, then end the session and check the desktop. CouchMode restores supported settings it changed; it does not replace Windows or promise exact window geometry.

Once that works, use the [Windows console-style setup guide](content:guide-windows-console) to decide whether optional display or audio automation would remove another repeated step.
